# 🤖 **Image Classification Using CNN and ResNet Architecture** 🧠📸
# 🚀 **Overview**
🚀 **Proud to share my latest Deep Learning project**, where I implemented a **Convolutional Neural Network (CNN)** using the **ResNet (Residual Network)** architecture to perform **image classification** with impressive accuracy! 💡

-----

# 🔍 **Project Highlights:**
📌 Built a **deep learning model** leveraging **ResNet** for advanced feature extraction and improved performance.

🧠 Utilized **TensorFlow** and **Keras** frameworks for model creation and training.

🧹 Preprocessed and augmented image data to enhance model generalization.

📈 Achieved high accuracy by fine-tuning hyperparameters and preventing overfitting through **residual connections**.

💻 **Tools Used:** Python 🐍 | TensorFlow 🔢 | Keras 🧠 | NumPy 🔢 | Matplotlib 📊 | OpenCV 📷

-----

#💡 **Key Insights:**
This project demonstrates how **ResNet’s skip connections** overcome the **vanishing gradient problem**, enabling the training of **very deep neural networks** for superior image recognition.
